## Agent Roles (hierarchy low → high)
1. Field Agent — direct customer sales
2. Senior Agent — experienced field agent
3. Zone Manager — manages a city/zone
4. Regional Manager — manages a country region

## Sale Statuses
- completed — sale finalized and counted in revenue metrics
- pending — sale in progress, exclude from revenue totals
- cancelled — sale did not go through, exclude from all metrics
